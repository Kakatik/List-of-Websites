How to pirate safely

Starting off, you will need a good browser for privacy, for example Firefox

For torrenting, I recommend using a good torrent client like qbittorrent. Also downloading files through torrenting can cause issues with your ISP, so using a VPN is a must in most countries. (For example use Mullvad VPN or use Proton VPN)

For more secure browsing in Firefox, you should also add as an extension Ublock Origin as it blocks trackers and malicious ads from sketchy websites or piracy websites.
